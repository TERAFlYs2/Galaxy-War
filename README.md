# Galaxy-War
A spaceship game. Destroy enemy ships, collect bonuses, and set records!

## About the project
This is a 2D arcade game about space warfare against alien ships seeking to conquer the planet. You've been sent into space on a laser-equipped spaceship to destroy them. But the longer you fight, the more of these ships appear, so various randomly generated combat bonuses will help you

## What has been implemented
- Custom gameplay loop;
- Infinite space effect with parallax and multiple nebula layers;
- Spaceship control with smooth acceleration and deceleration;
- Custom collision system (ship collider);
- Shooting system;
- Added bonuses: increased shooting speed, protective shield, and increased movement speed;
- Enemy ship spawning;
- Smooth exponential increase in enemy movement speed with a maximum value;
- Game timer;
- Interactions between the player, enemies, and bonuses;
- Health system

## How to play

### Objective
You need to destroy enemy alien ships. But be careful! There are more and more of them, but luckily, random bonuses that fly past will help you fight. Break battle records and save the galaxy!

### Controls
- **← →** — move
- **Space** — shoot

### Gameplay
1. Use the ← and → arrow keys to move the spaceship;
2. Avoid enemy ships and collect power-ups;
3. Destroy enemies and survive as long as possible;
4. Try to achieve the highest score
